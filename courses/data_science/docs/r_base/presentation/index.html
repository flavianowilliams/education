Objetos e funções no R

  • Objeto é tudo que pode ser criado e armazenado na memória (vetor, lista, função, gráfico, modelo estatístico, etc).

  • Um objeto pode ser criado utilizando o operador de atribuição <-,

objeto <- função

Exemplo:

valor <- function(x) {return(x)}
print(valor)
function (x) 
{
    return(x)
}

Estrutura de dados principais no R

  • Vetores atômicos: Formado por elementos do mesmo tipo.
  vetor_letras <- c("a", "b", "c", "d")
  vetor_letras
[1] "a" "b" "c" "d"
  vetor_numeros <- c(1, 2, 3, 4)
  vetor_numeros
[1] 1 2 3 4
  • Vetores recursivos (listas): Podem ser formados por elementos de tipos distintos.
  lista <- list("a", 1, TRUE, NA)
  lista
[[1]]
[1] "a"

[[2]]
[1] 1

[[3]]
[1] TRUE

[[4]]
[1] NA

Lista nomeada

Os elementos de uma lista podem ser nomeados

  lista_nomeada <- list(caracter = "a", numero = 2, logico = TRUE, dado_faltante = NA)
  lista_nomeada
$caracter
[1] "a"

$numero
[1] 2

$logico
[1] TRUE

$dado_faltante
[1] NA

Lista nomeada

Para acessar um item da lista, basta usar o operador $.

  lista_nomeada$caracter
[1] "a"
  is.na(lista_nomeada$dado_faltante)
[1] TRUE
  as.character(lista_nomeada$numero)
[1] "2"
  lista_nomeada$logico <- FALSE
  lista_nomeada$logico
[1] FALSE

Vetores e listas aumentadas

Vetores e listas aumentadas são vetores ou listas que possuem atributos. Os atributos podem ser acessados a partir do comando attributes.

data <- as.Date("2026/06/09")
attributes(data)
$class
[1] "Date"
vetor_atomico <- c(1, 2, 3, 4)
attributes(vetor_atomico)
NULL

Atributos de vetores aumentados

  • Nome: Usados para nomear os elementos de uma lista ou um vetor.
scores <- c(88, 92, 79)
attr(scores, "names") <- c("Alice", "Bob", "Charlie")
names(scores)
[1] "Alice"   "Bob"     "Charlie"
scores
  Alice     Bob Charlie 
     88      92      79 
attributes(scores)
$names
[1] "Alice"   "Bob"     "Charlie"

Atributos de vetores aumentados

  • Dimensão: Define a dimensão de matrizes e arrays que são construídos a partir de um vetor.
vec <- c(1, 2, 3, 4)
matriz <- matrix(vec, ncol = 2)
matriz
     [,1] [,2]
[1,]    1    3
[2,]    2    4
dim(matriz)
[1] 2 2

No comando ao lado, construimos uma matriz com o comando matrix a partir do vetor vec, em seguida acessamos o seu atributo dim, que no caso indica a ordem da matriz de 2 linhas e 2 colunas.

Funções

Uma função é definida pelo comando function

funcao <- function(x) return(x)
funcao(4)
[1] 4

A princípio o R possui um repertório imenso de funções para diversos tipos de tarefas

Vetorização

Permite aplicar funções a um vetor inteiro de uma só vez. Isso permite realizar o cálculo de maneira mais limpa e rápida, ou seja, mais eficiente.

  vetor_real <- -2:2
  vetor_real
[1] -2 -1  0  1  2
  vetor_complexo <- as.complex(vetor_real)
  vetor_complexo
[1] -2+0i -1+0i  0+0i  1+0i  2+0i
  sqrt(vetor_complexo)
[1] 0.000000+1.414214i 0.000000+1.000000i 0.000000+0.000000i 1.000000+0.000000i
[5] 1.414214+0.000000i
  vetor_fracoes <- 1:4
  vetor_fracoes
[1] 1 2 3 4
  vetor_angulo <- pi*vetor_fracoes/2
  vetor_angulo
[1] 1.570796 3.141593 4.712389 6.283185
  cos(vetor_angulo)**2+sin(vetor_angulo)**2
[1] 1 1 1 1
